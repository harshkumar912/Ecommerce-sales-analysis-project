🛒 E-Commerce Sales & Customer Analytics

📌 Project Overview
An end-to-end data analytics project exploring customer purchasing behavior, regional performance, and category-wise revenue distribution using **SQL Server**, **Python (Pandas, Seaborn)**, and **Microsoft Excel**.


🛠️ Tech Stack & Skills Demonstrated
* **SQL Server (SSMS):** Relational schema design, CTEs, Aggregations, Window Functions (`DENSE_RANK`), Customer Value Segmentation.
* **Python:** Data cleaning, Pandas aggregation, Seaborn/Matplotlib visualization.
* **Microsoft Excel:** Executive KPI Dashboard, Formatted Tables, Summary Metrics (`SUMPRODUCT`).


 📊 Key Business Insights
1. **Total Revenue:** ₹8,18,900 across 49 customer orders.
2. **Top Regional Market:** Delhi recorded highest total sales volume, followed by Gurugram and Noida.
3. **Category Performance:** Electronics generated the largest share of revenue (~77.2%).
